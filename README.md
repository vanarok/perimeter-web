# Периметр — браузерная версия

Прототип MVP тактического шутера от третьего лица: отряд на вылазке, игрок отдаёт приказы.

Играть: https://vanarok.github.io/perimeter-web/

Здесь только собранная веб-версия (Godot 4.7, WebGL 2). Нужен браузер с WebGL 2 (Chrome, Firefox, Safari 17+), загрузка около 47 МБ.

## Управление

- щёлкнуть по игре, чтобы захватить мышь (Esc — отпустить);
- 1–5: выбрать бойца; ЛКМ: идти / атаковать; Shift+ЛКМ: весь отряд;
- ПКМ: держать позицию; Q: все за мной; Z / X / C: присед / лечь / сам;
- V: сменить оружие; F / H: в машину / все в машину; E: поднять раненого;
- Tab: тактическая пауза; WASD и колесо: камера; F1: подсказки.
